# Голосовой ассистент

Прототип десктопного приложения в режиме чата с искусственным интеллектом для создания, изменения и удаления задачи, встречи или напоминания. Ассистент понимает естественную речь, работает с относительными датами и поддерживает голосовой ввод/вывод.

## Инструкция к запуску:

### I. Готовая программа
 1. Перейдите в раздел "Releases".
 2. Выберите релиз с тегом "v1.0.1".
 3. Скачайте установочный файл "DescVoice.Setup.1.0.1.exe".
 4. Запустите скачанный установщик.
 5. Выберите, для кого устанавливаете программу (для всех пользователей или только для себя).
 6. Выберите папку установки и нажмите кнопку "Установить".
 7. Запустите приложение.
 8. На клавиатуре нажмите комбинацию клавиш Win + R.
 9. В открывшемся окне введите:
```bash
%APPDATA%\DescVoice
```
 10. В этой папке создайте текстовый файл.
 11. Добавьте в этот файл ваши ключи от Yandex Cloud:
```bash 
YANDEX_CLOUD_API_KEY=ваш_API_КЛЮЧ
YANDEX_CLOUD_FOLDER=ваш_Folder_ID
DEBUG=0
```
 12. Сохраните файл через "Сохранить как...". В поле "Имя файла" введите название ".env" (обязательно в кавычках). В поле "Тип файла" выберите "Все файлы". Сохраните файл (Файл должен сохраниться с названием .env без расширения txt).
 13. Откройте диспетчер задач. В поиск введите "DescVoice". Нажмите по ней правой кнопкой мыши и снимите задачу.
 14. Запустите приложение.

### II. Сборка программы  
 Требования:
 * Python 3.9+;
 * Node.js и npm;
 * Yandex Cloud API-ключ и Folder ID.
 1. Скачайте файлы проекта.
 2. Установите зависимости Node.js:  
```bash 
npm install
```
 3. Найдите файл .env.example и создайте его копию с именем .env.
 4. В файле .env добавьте ваши ключи от Yandex Cloud:
```bash 
YANDEX_CLOUD_API_KEY=ваш_API_КЛЮЧ
YANDEX_CLOUD_FOLDER=ваш_Folder_ID
DEBUG=0
```
 5. Запустите сборку интерфейса:  
```bash 
npm run desktop
```
 6. Запустите приложение.

## Архитектура

Проект построен на основе клиент-серверной архитектуры с четким разделением ответственности: интерфейс (Electron + React) взаимодействует с локальным ИИ-бэкендом (Python + FastAPI) через REST API.

## Стек технологий:

* Фронтенд: JavaScript & React, Electron, Vite, HTML / CSS.
* Бэкенд: Python 3.9+, FastAPI, Uvicorn, SpeechRecognition, pyttsx3 / Yandex SpeechKit, SQLite, PyInstaller.
* Языковая модель (LLM): YandexGPT (aliceai-llm/latest).
* Инструменты разработки: PyCharm, Visual Studio Code, Git, GitHub.

## Обоснование технических решений

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;В процессе проектирования архитектуры принято решение разделить интерфейс (React), системную логику (Electron) и обработку речи (Python). Это позволило обеспечить независимое обновление компонентов и упростить процесс отладки.  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;При выборе языковой модели рассматривались локальные решения (Hugging Face) и облачные API (Yandex AI Studio). Критерии оценки: доступность, поддержка Tool Calling, скорость ответа, понимание контекста, работа с нестандартными ситуациями, качество выполнения задач и общение. По итогам проведенных тестов выбрана модель aliceai-llm/latest от Яндекса. Она показала лучший баланс между качеством понимания русского языка и стоимостью (0.5 руб./1000 входных токенов, 1.2 руб./1000 выходных). В среднем один запрос с учетом контекста обходится около 2 рублей.  
&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Для хранения данных использована встроенная локальная база SQLite. Это решение обеспечило приватность данных (информация не передается на сторонние серверы) и исключило необходимость развертывания отдельного сервера баз данных.

## Потенциал развития продукта:

* Добавление повторяющихся задач (например, каждый понедельник);
* Добавить продолжительность события (сколько событие будет длиться);
* Изменение стилистики общения (секретарь, дружественный, близкий человек);
* Изменение голоса ассистента на мужской/женский;
* Возможность изменить язык;
* Добавление светлой темы;
* Интеграция с реальным календарем;
* Поддержка нескольких пользователей;
* Мобильная версия.
